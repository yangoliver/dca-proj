### 2.2 `calculator.py` — 弹性股数法

```python
def calc_lots(amount: float, price: float) -> dict:
    """
    弹性股数法计算

    参数：
        amount  — 本次定投金额（元），例如 500
        price   — 当前市价（元/份），例如 4.20

    返回：
        lots      — 实际买几手（整数）
        shares    — 实际买多少份
        spent     — 实际花了多少钱
        leftover  — 滚存余额
    """
    lot_size = 100  # A股ETF：1手=100份
    max_lots = int(amount // (price * lot_size))  # floor除法
    shares   = max_lots * lot_size
    spent    = round(shares * price, 2)
    leftover = round(amount - spent, 2)
    return dict(lots=max_lots, shares=shares, spent=spent, leftover=leftover)
```

**示例**：
```
输入：¥500 / ¥4.20
输出：lots=1, shares=100, spent=¥420, leftover=¥80
→ 今天买100份，花¥420，剩¥80滚存
```

## 四、双周定投日期计算

```python
from datetime import datetime, timedelta

def next_investment_date(first_date_str: str) -> str:
    """
    计算下一个定投日期
    规则：从第一次买入起，每隔14天执行一次
    """
    first = datetime.strptime(first_date_str, "%Y-%m-%d")
    today = datetime.now()
    days_elapsed = (today - first).days
    periods_passed = days_elapsed // 14
    next_date = first + timedelta(days=(periods_passed + 1) * 14)
    return next_date.strftime("%Y-%m-%d")

def is_investment_day(first_date_str: str) -> bool:
    """今天是不是定投日？"""
    first = datetime.strptime(first_date_str, "%Y-%m-%d")
    today = datetime.now()
    days_elapsed = (today - first).days
    return days_elapsed >= 0 and days_elapsed % 14 == 0
```
