## 一、1 万元够不够（先做）

### 1.1 先写一个分析工具

在 `tools/` 下新建 `smile_curve_analyzer.py`。

这个工具接收两个参数：

- ETF 代码（如 `510580`）
- 总投资金额（如 `10000`）

输出：

- 历史最大跌幅 + 发生时间
- 完整微笑曲线需要多久、总投入多少
- 两个建议方案：
  - **方案 A**：降低每期金额，延长周期覆盖微笑曲线
  - **方案 B**：保持每期金额，追加总投资

**工具设计要求**：

```python
def analyze_investment_plan(etf_code, total_amount, interval_days=14, per_amount=500):
    """
    分析给定总投资金额能否覆盖一条完整微笑曲线。

    返回：
    - 最大跌幅（%）
    - 完整微笑曲线所需月数
    - 完整微笑曲线所需总投入
    - 方案A：降低每期金额后的月数 + 每期金额
    - 方案B：追加金额后需追加多少
    """
```

**分析逻辑**：

1. akshare 拉取 ETF 过去 5 年历史数据
2. 找到跌幅最深的一段（最大回撤）
3. 模拟定投：每 14 天投 ¥500，算出覆盖这段微笑曲线需要多少期、共投入多少
4. 用总金额和所需投入对比，判断够不够
5. 如果不够，给出方案 A（减金额延周期）和方案 B（追加金额）

## 二、PE < 30% 止盈资金加回机制

### 2.1 先读 Day 6–9 的历史记录

打开 Day 6 报告（第 13、31、64 页）和 Day 9 核对材料（方案 B·③ 持有），找到现在 pe_low 的提示词。

### 2.2 两条策略，选一条

PE < 30% 时，货基里的止盈资金怎么处理？两条路，性质完全不同。

---

**策略 A：保守型——止盈资金不回来**

| 规则 | 内容 |
|------|------|
| 性质 | 止盈资金是"多赚的防守资金"，不是仓位 |
| PE < 30% 时 | inspector 只提醒"市场低估"，不提加仓 |
| 货基里的钱 | 长期放着，不回到定投系统 |
| inspector pe_low 提示词 | "市场处于低估区间（PE分位 < 30%）。你的止盈资金在货基里，按策略 A 不做额外操作，继续正常定投。" |

**优点**：规则极简，不需要判断时机，没有"钱回来了怎么买"的问题。
**缺点**：止盈资金没有复利。

---

**策略 B：机会型——低位额外加仓**

在策略 B 内部，两条执行路径，核心差异是"什么时候加、加多少"。

---

**B1：等深坑——PE 极度低估时加仓**

| 规则 | 内容 |
|------|------|
| 触发条件 | PE 分位 < 20%（不是 < 30%，门槛更高） |
| 加仓上限 | 货基余额的 50%，单次最多 ¥500 |
| 停止条件 | PE 回到 30% 以上，或货基清零 |
| 性质 | 只在极端低位出手，次数少、单次可能大 |
| inspector pe_low 提示词 | "市场极度低估（PE分位 < 20%）。你有 ¥__ 在货基里，可考虑额外加仓 ¥__（不超过 ¥500，且不超过货基的 50%）。是否加仓、由你判断。" |

---

**B2：分批入场——PE < 30% 开始，每期加一点**

| 规则 | 内容 |
|------|------|
| 触发条件 | PE 分位 < 30%（先到先加） |
| 加仓上限 | 每期不超过 ¥300，也不超过货基余额的 30% |
| 停止条件 | PE 回到 30% 以上，或货基清零 |
| 性质 | 门槛低、每次少，在低估区间内分散进入 |
| inspector pe_low 提示词 | "市场处于低估区间（PE分位 < 30%）。你有 ¥__ 在货基里，可在本期定投之外额外加仓 ¥__（不超过 ¥300，且不超过货基的 30%）。是否加仓、由你判断。" |

---

**对比**

| | B1 等深坑 | B2 分批入场 |
|--|-----------|-------------|
| 触发门槛 | PE < 20%（更保守） | PE < 30%（更积极） |
| 单次上限 | ¥500 | ¥300 |
| 次数 | 少 | 多 |
| 均价风险 | 可能买在半山腰 | 分批平滑 |

---

## 三、Cron 巡检频度

### 3.1 查现状

运行 `cron list`，确认现有 Cron 状态。

### 3.2 重新设计

推翻月度巡检，改用**每日轻量巡检 + 有情况才推**。

触发推送的条件：

| 条件 | 动作 |
|------|------|
| 浮盈 ≥ 20%（接近止盈） | 推送：接近止盈线，注意观察 |
| 浮亏 ≥ 15% | 推送：浮亏预警，检查是否偏离纪律 |
| PE 分位 < 30% | 推送：低估区间，止盈资金可考虑额外加仓 |
| PE 分位 > 70% | 推送：估值偏高，留意止盈机会 |
| 距下次定投日 ≤ 2 天 | 推送：定投提醒（金额、手数） |
| 无以上情况 | Cron 静默，不打扰 |

### 3.3 修改 inspector.py

新增"无情况静默"模式，更新每日巡检 Cron。
