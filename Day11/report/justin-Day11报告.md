## 二、PE < 30% 加回机制

### 2.1 加回方式对比

| | 方案 A：等深坑 | 方案 B：分批入场 |
|--|----------------|-----------------|
| 性质 | 极度低估时出手 | 低估区间内分批加仓 |
| 触发条件 | PE 分位 < 20% | PE 分位 < 30% |
| 单次上限 | ¥500 | ¥300 |
| 比例上限 | 货基余额的 50% | 货基余额的 30% |
| 复利机会 | 有 | 有 |
| 复杂度 | 中 | 中 |

### 2.2 我的推荐

推荐方案 A（等深坑），理由：PE<20% 门槛更高，出手次数少但每次更有针对性。止盈资金本身不多（当前货基余额 ¥0，尚无卖出记录），不值得在 PE<30% 就开始频繁小额加回。等真正深坑再出手，纪律性更强。

### 2.3 出资人拍板

> 出资人确认：方案 A（等深坑）

### 2.4 落地代码

inspector.py L168-189，PE<20% 时：

```
货基余额 = sum(止盈卖出记录金额)
加仓额 = min(500, 货基余额 × 50%)
加仓额 = min(加仓额, 货基余额)
```

提示词："市场极度低估（PE分位 X% < 20%）。你有 ¥___ 在货基里，可考虑额外加仓 ¥___（不超过 ¥500，且不超过货基的 50%）。是否加仓、由你判断。"
