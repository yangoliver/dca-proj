# 理财定投实习计划（dca-proj）

Oliver 带高中毕业生杨知行做的 21 周实习项目——通过中证500 ETF 定投学习金融投资与 AI Native 工作方式。

> 注：本项目原名"量化先锋实习计划"，但考虑到核心活动是被动定投而非量化策略，于 2026-07-18 正式更名。

## 项目本质

- **投资线**：用真金白银（¥10,000）在 A 股做定期定额投资（DCA），理解定投纪律
- **公司线**：用 QClaw 主导的 AI 协作体系（Qoder CN / akshare / WorkBuddy / Codex）完成从工具安装到自动化运营的全过程

定投核心原则：**到了时间就买，不判断，不择时。**
