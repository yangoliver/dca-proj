# 月度汇报 Skill 设计

> **杨知行任务**：理解这份 Skill 的职责边界，然后让 QClaw 把它写成 SKILL.md。
>
> **Skill 定位**：只做一件事——读取 `data/portfolio.xlsx` 的持仓数字，按模板格式填进月报的第一节。反思、纪律、计划——这些是你自己写的，Skill 不替你说。
>
> **Skill 触发词**：`写月度汇报`、`生成月报`、`月报`

---

## Skill 需要什么信息

### 第一节：持仓现状（Skill 自动填）

**数据来源**（Skill 自己查）：

| 字段 | 来源 |
|------|------|
| 累计投入、累计份额、持仓均价 | 读 `data/portfolio.xlsx` Sheet1 |
| 当前价格 | 新浪接口（510580） |
| 当前市值、浮盈亏 | Skill 计算 |
| 各期买入记录 | 读 Sheet1 + Sheet3 |

### 第二节～六节（杨知行自己填）

- **第二节**：纪律执行情况（你有没有择时、跳过、改金额？）
- **第三节**：本月学习总结（三段话）
- **第四节**：能力矩阵对比（5维度，Day1 vs 现在）
- **第五节**：下月计划
- **第六节**：给 Oliver 的话

这些 Skill 帮不了你——因为那是**你的经历、你的反思**。
